# QuantMind 页面缓存目录

QuantMind 0.1.2 会把成功的只读 API 响应保存到 `pages/<页面标识>/`，用于加速页面重新进入和服务重启后的首次恢复。

- 实时行情缓存 15 秒，普通市场数据缓存 2 分钟，资讯缓存 10 分钟，明确的历史日期缓存 24 小时。
- 缓存按登录用户隔离；登录令牌不会写入文件。
- 页面内写操作会清除该页面缓存，带 `refresh=true` 的请求会绕过并更新缓存。
- 启动时自动清理过期、损坏和旧版本缓存，总容量上限为 512 MiB。
- 此目录中的运行时 JSON 文件已被 Git 忽略，可以在服务停止后安全删除；删除只会让下一次请求重新获取数据。
